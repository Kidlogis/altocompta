# Extensions

Les extensions d'AltoCompta se placent ici, un dossier par extension (`plugins/<identifiant>/`).

La façon la plus simple de les installer : **Extensions › Importer une extension**, avec le fichier `.zip`
reçu après l'achat. Un aperçu s'affiche avant toute installation, et l'ancienne version est sauvegardée en
cas de mise à jour. On peut aussi décompresser le dossier d'une extension ici, à la main.

Le catalogue des extensions disponibles est dans **Boutique**.

Une extension est du code PHP exécuté avec les droits de l'application : n'installez que des fichiers
dont vous connaissez la provenance.
